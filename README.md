# Dozer Remote

A browser dashboard for the Dozer Remote project.

## Website

After GitHub Pages is enabled and the workflow completes, the site will be available at:

https://owarellano-eng.github.io/dozer_remote/

## Current status

The published page is a dashboard/landing page only. It does not currently stream a PC screen or send remote input. A secure connection service and Windows host still need to be configured.

Remote access must use a service approved for the networks and devices involved. Do not disguise traffic, bypass school filters or Chromebook management, publish pairing codes, or expose the Windows host directly to the public internet.

## Publish with GitHub Pages

1. Open the repository Settings, then Pages.
2. Under Build and deployment, choose GitHub Actions as the source.
3. Push to the main branch or run the Deploy Dozer Remote website workflow manually under Actions.
4. Wait for the deployment workflow to finish, then open the website URL above.

## Project files

- index.html — browser dashboard
- .github/workflows/pages.yml — GitHub Pages deployment workflow
